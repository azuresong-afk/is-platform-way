# Заглушки продуктов

Крошечные FastAPI-приложения, которые ведут себя как «Сканер», «Устранение» и «Аттестация» со стороны контракта платформы v1.1: отдают манифест, `/summary`, `/search`, проверяют JWT платформы по JWKS и принимают события с HMAC. Нужны, чтобы разрабатывать и тестировать платформу без настоящих продуктов.

| Каталог | Продукт | Что отдаёт |
|---|---|---|
| `fake-scanner/` | `scanner` | сводка уязвимостей по уровням, последний прогон, поиск по находкам |
| `fake-vm/` | `vm` | открытые и просроченные заявки, ближайшее окно, поиск по заявкам |
| `fake-grc/` | `grc` | объекты, % реализации мер, готовность документов |

Общая часть — `fakeproduct/`; `fakeproduct/auth.py` — эталонная проверка токена на стороне продукта (можно переносить в продукты).

Запуск без Docker:

```bash
cd dev
pip install -r requirements.txt
PLATFORM_JWKS_URL=http://127.0.0.1:18010/.well-known/jwks.json \
  PYTHONPATH=. uvicorn main:app --app-dir fake-scanner --port 18000
```

Переменные: `DATABASE_URL` (в комплекте: заглушка пишет строку в таблицу `fake_boot` своей базы при старте, `/health/ready` проверяет соединение — для `dev/suite-restore-check.sh`), `PLATFORM_JWKS_URL`, `PLATFORM_EVENTS_SECRET`, `FAKE_DELAY_SECONDS` (задержка `/summary` и `/search`), `FAKE_FAIL=1` (ответ 500 — проверка карточки «недоступен»).

Тесты: `cd dev && pytest`.
